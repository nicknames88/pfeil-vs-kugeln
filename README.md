# Pfeil vs. Kugeln

**Hier spielen: https://pfeil.vercel.app**


Ein Top-down-Shooter, den ich selbst programmiert habe. Du bist ein Pfeil,
läufst mit WASD und zielst mit der Maus. Die Gegner sind Kugeln, die
zurückschießen.

**Spielen:** einfach `index.html` im Browser öffnen — das ganze Spiel steckt in
dieser einen Datei. Kein Server, keine Installation, keine einzige zusätzliche
Datei.

## Was drin ist

- **500 Level** in fünf Stufen, alle 10 Level ein Boss
- **39 Waffen** in fünf Läden: Forschungsbaum, Labor, Werkstatt, Schmiede, Arsenal
- **16 Bosse**, je eigenes Angriffsmuster
- **13 Gegnertypen**, nach jedem Boss kommt ein neuer dazu
- **9 Landschaften** — Wüste, Eisfeld, Vulkan, Tiefsee, Raumstation und mehr
- **Rucksack**: Jede Waffe hat Gewicht und Munition, du kannst nicht alles mitnehmen
- **Aufträge**: überleben, einsammeln, verteidigen
- **Schießstand** zum Ausprobieren jeder Waffe
- Musik und alle Geräusche werden live im Browser erzeugt — keine Audiodatei

## Zusammen spielen

Im Menü auf **👥 Zusammen spielen**. Einer eröffnet und bekommt einen Code wie
`KRW-4T9`, der andere tippt ihn ein. Kein Konto, keine Installation — die beiden
Rechner reden direkt miteinander. Zu zweit kommen etwa doppelt so viele Gegner.

## Steuerung

| | |
|---|---|
| WASD / Pfeiltasten | laufen |
| Maus | zielen und schießen |
| 1–9, Q/E, Mausrad | Waffe wechseln |
| Leertaste, F | Fähigkeiten |
| P oder Esc | Pause |
| M / N | Ton / Musik |

Auf Handy und Tablet: linker Daumen läuft, rechter Daumen zielt und schießt.
Im Menü umschaltbar auf Zielhilfe.

## Spielstand

Der Fortschritt liegt im Browser. Über **Spielstand sichern & laden** im Menü
bekommst du ihn als Text, den du dir selbst schicken und auf einem anderen
Gerät wieder einsetzen kannst.
